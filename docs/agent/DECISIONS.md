# Decisions (quick reference)

Terse log for agents/next context window. Rationale lives in `docs/architecture/decisions/` (ADRs).

| #   | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | Why (short)                                                                                                                                                       |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D1  | **Single Next.js 16.3 app (App Router) at repo root**, modular monolith: `src/domain` (pure, isomorphic), `src/server` (server-only: db, auth, storage, images, catalog, admin), `src/app` (thin routes), `src/components` (ui/store/admin). No monorepo packages.                                                                                                                                                                                                                                    | Simplest structure with clean boundaries; one deployable.                                                                                                         |
| D2  | **Cache Components on** (`cacheComponents: true`). Public data via `'use cache'` + `cacheTag` + custom `cacheLife("storefront")`; admin mutations call `updateTag()` for read-your-writes. Tags: `catalog`, `settings`, `reviews` (coarse by design).                                                                                                                                                                                                                                                 | Static shells + instant nav; explicit invalidation satisfies "reflects on live site immediately".                                                                 |
| D3  | **PostgreSQL 17 + Drizzle ORM 0.45 + postgres.js**. SQL migrations in `drizzle/` (generated + custom SQL). Enums are `text` + CHECK constraints from `src/domain`. Money = integer PKR.                                                                                                                                                                                                                                                                                                               | Portable plain Postgres (Supabase/Neon/RDS); typed, light, SQL-first.                                                                                             |
| D4  | **Local infra = docker compose**: `postgres:17-alpine` (:54329, DBs `usba` + `usba_test`) and **RustFS** S3 server (:9100). Not the Supabase CLI stack.                                                                                                                                                                                                                                                                                                                                               | We use Postgres + S3 only; MinIO no longer ships community images.                                                                                                |
| D5  | **Storage port** `ObjectStorage {put, deleteMany, publicUrl}` with S3 adapter (AWS SDK v3) and in-memory test adapter. Works with Supabase Storage S3, R2, S3, RustFS.                                                                                                                                                                                                                                                                                                                                | Provider lock-in contained in one file.                                                                                                                           |
| D6  | **Images**: server `sharp` pipeline → magic-byte check, 10 MB cap, 40 MP cap, rotate, strip metadata, WebP variants `[320,480,640,960,1280,1600]` at `<key>-<w>.webp`, 16px blur placeholder. Served via plain `<img srcset>` from `MEDIA_BASE_URL`. No next/image optimizer, no AVIF.                                                                                                                                                                                                                | No vendor image API dependency; avoids 2026 Next image-optimizer CVEs; CDN-friendly immutable objects.                                                            |
| D7  | **Admin auth = custom**: Argon2id (@node-rs/argon2 defaults = OWASP), opaque 256-bit token cookie (`__Host-usba_admin` on HTTPS), SHA-256 stored in `admin_sessions`, 24h absolute + 8h idle, logout deletes row. `requireAdmin()` in **every** admin page and Server Action; `proxy.ts` is only an optimistic redirect. Postgres fixed-window rate limits (login 20/IP, 8/account per 15 min).                                                                                                       | No vendor auth; single owner; OWASP session guidance; proxy bypass CVEs.                                                                                          |
| D8  | **Listings filter client-side** over the server-rendered category list (pure `applyFilters` in `src/domain/listing.ts`), state in URL query (`color,min,max,sub,stock,sort`). Canonical = base listing URL.                                                                                                                                                                                                                                                                                           | Catalogue is tens of items per listing: instant filtering, fully static/cached HTML, crawlable links. Switch to server filtering when listings exceed ~300 items. |
| D9  | **Search** = pure ranker `src/domain/search.ts` (prefix/substring/1-typo), used by client live suggestions over a small JSON index (`/api/search-index`) and by server `/search` page.                                                                                                                                                                                                                                                                                                                | Instant suggestions, no search infra. Upgrade path: Postgres pg_trgm / FTS.                                                                                       |
| D10 | **Categories**: 2-level tree (L1 footwear/bags/accessories/clothing; L2 per §11.1). `/shop/<slug>` resolves L1, L2, or virtual collections `collab`, `sale` (reserved slugs). Products attach to an L2 category. Collab = `collab_partner` handle (checkbox in admin).                                                                                                                                                                                                                                | Matches §11.1/§11.3 routes and AS-09.                                                                                                                             |
| D11 | **Product URL** `/product/<slug>`; `/product/USBA-001` (code) redirects to slug. Product code `USBA-NNN` from sequence.                                                                                                                                                                                                                                                                                                                                                                               | Readable URLs + requirement's Product ID.                                                                                                                         |
| D12 | **Ordering**: `wa.me/<digits>?text=` built by pure `src/domain/ordering.ts`; out-of-stock disables ordering; preorder uses preorder wording; sizes required when product has sizes. Instagram via `ig.me/m/<handle>` (no prefill).                                                                                                                                                                                                                                                                    | CS-07/08/18/24.                                                                                                                                                   |
| D13 | **Orders schema** = `orders` + `order_items` (snapshots) + `order_status_events` (history), `channel` column → future web checkout extends it. No payments now.                                                                                                                                                                                                                                                                                                                                       | AS-12/13 + future checkout path.                                                                                                                                  |
| D14 | **Security headers** via next.config: static CSP (`'unsafe-inline'` scripts required by Next without nonces), frame-ancestors none, nosniff, HSTS on https, `/admin` no-store + noindex.                                                                                                                                                                                                                                                                                                              | Nonce CSP would force dynamic rendering of the whole storefront.                                                                                                  |
| D15 | **Design**: Petal `#fbf6f7`, Ink `#2a1520`, Cherry `#a8123a`, Ballet `#f2c9d4`; Bodoni Moda (display) + Hanken Grotesk (UI). Tokens in `src/app/globals.css` `@theme`. Photos square-cornered 4:5; shadows only on overlays; sentence case, no all-caps labels.                                                                                                                                                                                                                                       | Brand-specific (cherry/coquette motifs from the product line), not template defaults.                                                                             |
| D16 | **Env**: server-only typed `env()` (zod) in `src/server/config/env.ts`; no `NEXT_PUBLIC_*`; client receives computed values via props. Scripts run with `tsx --conditions=react-server`.                                                                                                                                                                                                                                                                                                              | One artifact per environment; no secret leakage.                                                                                                                  |
| D17 | **i18n (CS-15)**: storefront under `app/[lang]` (`en`, `ur`), both prerendered; English keeps unprefixed URLs via `src/proxy.ts` rewrite (`/en/...` 308 → unprefixed); typed dictionaries in `src/i18n/dictionaries` (Urdu typed against English); `next/root-params` `lang()` in server components, `dictionaryFor(locale)` in client components; admin English-only with its own root layout; Urdu uses system Nastaliq/Naskh fonts (web font cost ~1 s LCP); WhatsApp order message stays English. | SEO-friendly static per-locale pages without breaking existing URLs.                                                                                              |
| D18 | **Hosting recommendation (superseded by D22)**: Docker (standalone) on a small always-on host (Render Starter) + managed Postgres (Neon/Supabase) + R2/Supabase Storage; single instance. AWS path = ECS Express Mode/Fargate + RDS + S3/CloudFront. Vercel Hobby is non-commercial → not allowed for a shop.                                                                                                                                                                                         | See docs/research/hosting.md.                                                                                                                                     |
| D19 | **Wishlist (CS-21)**: localStorage list of slugs; one delegated client provider (no per-card islands); shareable `/saved?items=` link.                                                                                                                                                                                                                                                                                                                                                                | No accounts; zero cost on listing hydration.                                                                                                                      |
| D20 | **Analytics (AS-19)**: first-party cookie-free events (`/api/events`, daily-salted visitor hash, 180-day retention) feeding the admin Insights panel; Plausible/GA remain optional providers.                                                                                                                                                                                                                                                                                                         | Requirement asked for GA metrics without credentials; privacy-friendly.                                                                                           |
| D21 | **Instagram (CS-22)**: owner-curated posts (`instagram_posts`) until Meta API credentials exist.                                                                                                                                                                                                                                                                                                                                                                                                      | Official feed needs a Meta app + token refresh.                                                                                                                   |
| D22 | **Hosting (supersedes D18)**: AWS always-free serverless in ap-southeast-2 (the owner's project account is locked to Sydney), DNS on Cloudflare Free (DNS only). CloudFront + ACM certificate + Lambda (OpenNext 4, Function URL locked by an origin secret) + Aurora DSQL + one S3 bucket + DynamoDB/SQS for the Next cache; CDK in `infrastructure/aws/cdk`. Schema kept DSQL-compatible (jsonb arrays, no deferrable unique, `drizzle/dsql` baseline tested against Drizzle).                      | Owner wants $0 with no feature compromises; see ADR 0014.                                                                                                         |
